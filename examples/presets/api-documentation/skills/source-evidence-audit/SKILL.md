# Source evidence audit

Build a working inventory from every supplied source type. Expand review rows
into atomic requirements: requested languages, body variants, field examples
and endpoint details. Map each requirement to its source and output location.
Read omitted ranges when tool output is truncated.

Use parsers to compute counts, set differences and joins. Compare dates before
claiming one event preceded another. Keep a record's exact customer tier, status
and identifiers separate from aggregate summaries. Preserve compound requirements
and their AND/OR meaning. Retain unresolved conflicts instead of inventing a
chronology or explanation.

Reopen all final documents and verify every inventory item, including final rows
and exceptional cases. Cross-check repeated claims against their original records.
Report gaps honestly; a successful format check does not establish factual accuracy.
