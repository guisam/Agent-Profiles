## Decided
Publish the Superpowers role experiment as a repository example and volunteer testing guide, not a Markdown preset. Preserve upstream resource directories, pin 7.0.2 and retain MIT attribution for extracted worker contracts. State structural and live evidence separately. Patch version 0.19.6 changes no runtime/schema; wiki source accompanies the PR and live publication follows merge.

## Tried and ruled out
No private paths, session IDs, lock files, signing configuration or raw transcripts are published. No native-plugin isolation failure or cost advantage is assumed. Trail's preset/repository conflict in the upgrade note is lexical: checks ran in a clean clone, exactly as the earlier learning requires, and no private scaffold was used.

## Watch out
The reproducible local example is not published-library resource installation. Six CLI resolutions pass for both host labels, but this does not establish live Codex behavior. Volunteers need exact versions, observable evidence and explicit permission for model runs. Existing historical reports are not full provider traces.
