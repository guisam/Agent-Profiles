## Decided
The approved documentation-writer verification addition was published as a native candidate only in an isolated Strata technical-writer migration project/store. start_migration selects an available skill as required, which composes the skill text into AGENTS.md. Therefore the earlier on-demand baseline is not a matched control. Run a fresh base and candidate with the same required loading mode; candidate export must differ only in the edited skill and its generated composition.

## Tried and ruled out
Run 20261023T191152Z-06b1ba used unchanged task/prompt/runtime and 600-second limits. Fresh control completed 4/4 documents in approximately 361 seconds; candidate timed out with only migration and partial API reference (2/4). It built a fact list and recognized unknown header details, but still emitted an invented header and unsupported webhook validation behavior. Post-run checks verified both arms' source/reference and managed harness bytes. Failed candidate has no successful completion attribution. Exact runner, candidate, protocol, forensic hashes and review are retained.

## Watch out
Keep this version unadopted. Partial absence of private issue IDs is not a complete audience-filtering pass when the missing documents include where the control leaked them. One timeout does not prove the instruction change caused it. No native evaluation eligibility plan/results, stock judge, held-out qualification or promotion was performed. Prefer a smaller separately identified next candidate over extending the failed attempt's budget or relabeling it successful. Source patch 0.2.1 records this experiment; no application behavior or schema changes.
